# M2 原生卡测试样例

这些是受检诊断程序，不是正式 SDK 能力声明。所有程序通过 `sdk/crt0.s`
和声明类型构建，没有相机固件地址。每次会话使用独立磁盘镜像，
不得在 QEMU 存活时由宿主修改文件。

`materials.py --out <新目录>` 对每个程序构建两次，独立解析 NLB、核对段长、
CRC 和真实重定位，再生成卡文件目录。还须用 `prepare_card.py` 制作每场镜像。
`layout.py` 重新编译所需 Runtime 偏移，保留原来观察的字节范围，拒绝与候选布局不符。
`scenario.py` 从原生菜单操作，每场运行两次并保存状态和原截图；脚本成功只代表
已执行的状态断言通过，最终画面仍须审阅。

| 程序 | MODE.TXT | 实际检查 |
|---|---|---|
| DATA.NLB | R / E / H | 非零初值、37 个清零变量、真实读写、ADRP 和 ABS64 指针调用；正常返回、主动退出或等待真实组合键 |
| LIMITS.NLB | AR / AE / AH | 16 个小分配、17 次拒绝、释放与复用互不重叠；留下全部对象供退出清理 |
| LIMITS.NLB | FR / FE / FH | 16 个实际文件句柄、17 次拒绝及关闭复用；留下句柄供退出清理 |
| LIMITS.NLB | UR | 尚未提供的绘图/输入接口明确返回不支持；跨目录、跨盘及写模式拒绝 |
| FIO.NLB | 不读取 | 有限循环打开、读取、关闭真实 FIO.TXT 并核对内容；仅实际组合键退出记正常完成 |
| DATA1–3.NLB | 无 | 各自检验实际数据与清零区后登记独立菜单项，保留代码和数据 |
| FOURTH.NLB | 无 | 无可写数据的第四个菜单扩展，用于区分常驻数量与内存块上限 |

H 样例只在有明确停止期限的自有 QEMU 会话中运行；诊断程序自身有限的循环延时
不改变模拟器时钟。程序不会自行读宿主控制文件，退出由真实菜单组合键触发。

分配槽、原厂分配器可用空间和程序代码/数据块预算是不同限制。16 个槽通过不证明
存在每程序总字节配额；原厂分配失败也不能当作块预算拒绝。原厂文件服务若先达到
更低数量，须记录真实错误，不伪造句柄凑足 16 个。

预算组合分别覆盖两个带数据扩展加 DATA 前台恰好占满六块，以及三个带数据扩展
后再开前台的拒绝；如先遇到原厂分配失败，保留失败并以明确的隔离预算候选另验。
真实相机、硬件缓存一致性和断电恢复仍不由这些结果证明。

`resident_materials.py` 另用已有资源诊断源构建四个无可写数据的扩展；六块预算尚有
余量时，第四项应因三个常驻项的数量上限被拒绝。`budget_scenario.py` 分别核对
这两种限制、实际名称、所有块的对齐与互不重叠、既有资源持续保留。

`rejections.py` 预制 30 项文件检查和执行检查输入，包含两端正常控制、缺失/未知类型、
段长、校验、重定位边界与未对齐、合法旧版只检查，以及被修改的封闭探针。
`reject_scenario.py` 通过真实菜单逐项核对，拒绝期间必须有完整的新观察记录。

若原厂分配器先于六块预算用尽，`reduced_materials.py` 可用已双构的程序制作
独立的两块/一个常驻配置材料；必须另建并完整核对该配置的候选，不能直接套在
原六块/三个常驻包上。它分别验证一个代码扩展与一个代码前台共存、一个带数据
扩展占满两块后拒绝前台，以及内存尚有余量时拒绝第二个常驻扩展；不能据此宣布
六块分配或带数据扩展与前台同时运行通过。

服务进行中退出专项可用 `scenario.py --attempts 1 --passive-points <受检声明>`，
卡材料须声明实际成功文字 `expected_text`。`api_exit_review.py` 独立核对分支、
恢复调用、服务结束后退出、未走强制终止及资源清理；需要对应候选的完整指令证据。
一次性观察点只证明一次实际退出，不能自动推广为同会话的多次观察。

`prepare_scenario.py` 单独验证准备模式的探针、SAFE_MODE 与旧版只检查，不能用
执行模式的成功结果替代。`resource_rejections.py` 接受独立推导的逐案期望和卡清单，
在启动前从实际镜像提取每个输入核对，随后检查零入口/零发布及准确错误；停机后
确认 STATE 不存在、原文件未变，或核对实际双记录内容与 CRC。页面检查不触发恢复。
`layout.py --additional-spec ... --select-fields ...` 合并并明确选择需要的观察字段，
仍由 C 头文件独立编译偏移；保持 128 个字段和原 Runtime 字节范围的限制。
